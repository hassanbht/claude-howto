# دستور بازنویسی مستندات

دستور `/doc-refactor`، برای استخراج، بازنویسی، و بهینه‌سازی مستندات‌های کد و markdown، از جمله `README.md`، `CONTRIBUTING.md`، `STYLE_GUIDE.md`، و سایر مستندات، استفاده می‌شود. این دستور، به‌صورت خودکار، مستندات را طبق استانداردهای کد‌نویسی، مستندات، و قوانین صحیح‌نویسی، به‌روز می‌کند.

## چیستی

دستور `/doc-refactor`:

- مستندات را تشخیص می‌دهد
- حذف یا توضیح‌پذیری کد، مستندات را روان‌تر می‌کند
- از استانداردهای کدنویسی پشتیبانی می‌کند
- می‌تواند بسته‌های تنظیم‌شده و فایل‌های پیک‌کردن را لیست کند
- برای مستندات تمام سطوح، می‌تواند مستندات را به‌روزرسانی کند

## مثال‌ها

### مثال ۱: روان‌سازی README

زمینه‌هایی در `README.md` را به‌دست آورید و مستندات را به‌صورت بهینه‌سازی شده، به‌روزرسانی کنید.

### مثال ۲: به‌روزرسانی مستندات

```bash
# روان‌سازی README
/doc-refactor README.md

# به‌روزرسانی مستندات
/doc-refactor docs/
```

## راه‌حل‌ها

- مستندات، طولانی‌ترین لیست‌ها را به‌دست آورید
- دستور `/doc-refactor` را اجرا کنید
- خط‌ها را برای پیک‌کردن‌های اصلی، به‌روزرسانی کنید

## مسائل و رفع مشکل

- مستند نبودن: مطمئن شوید که فایل‌ها در مسیر صحیح است
- فایل‌ها، به‌عنوان مستندات، پیک‌گرد هستند
- خطا در `claude /doc-refactor`: اطمینان حاصل کنید که مستندات، فایل‌های markdown هستند
