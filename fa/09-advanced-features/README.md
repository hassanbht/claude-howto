## مرور کلی

قابلیت‌های پیشرفته کلود کد، توانایی‌های پایه را به لایه‌های برنامه‌ریزی، استدلال، خودکار‌سازی و کنترل گسترش می‌دهند. این قابلیت‌ها، وظایف توسعه پیچیده‌تر، بررسی کد، فرآیندهای خودکار‌سازی و مدیریت چندسیشن را پشتیبانی می‌کنند.

**از قابلیت‌های پیشرفته اصلی شامل است:**

- **حالت برنامه‌ریزی** (Planning Mode): بیاموزید ساختار دقیق پیاده‌سازی را، قبل از شروع کدنویسی
- **تفکر گسترده** (Extended Thinking): استدلال عمیق‌تر برای مسائل پیچیده
- **حالت خودکار** (Auto Mode): بررسی امنیت پس‌زمینه قبل از هر مرحله
- **وظایف پس‌زمینه** (Background Tasks): وظایف طولانی‌مدت که سیشن را مسدود نمی‌کنند
- **حالت‌های مجاز** (Permission Modes): کنترل آنچه که کلود می‌تواند انجام دهد (`default`، `acceptEdits`، `plan`، `auto`، `dontAsk`، `bypassPermissions`)
- **حالت چاپ** (Print Mode): اجرا غیرتعاملی برای خودکار‌سازی و CI/CD (`claude -p`)
- **مدیریت سیشن** (Session Management): مدیریت چند سیشن
- **قابلیت‌های تعاملی** (Interactive Features): میانبرها، مدخل چندخطی، تاریخچه
- **ورودی صوتی** (Voice Dictation): صحبت کردن با حفظ فشار، پشتیبانی از ۲۰ زبان
- **کانال‌های پیام‌رسانی** (Channels): قنوات پیام‌رسانی که به سیشن در حال اجرا می‌توانند پیام بفرستند
- **کنترل از راه دور** (Remote Control): کنترل سیشن محلی از طریق Claude.ai یا اپلیکیشن Claude
- **سیشن‌های وب** (Web Sessions): کلود کد را در مرورگر اجرا کنید
- **اپلیکیشن دسکتاپ** (Desktop App): امکان diff دسکتاپ و مدیریت چندسیشن
- **لیست وظایف** (Task List): ردیابی پایدار وظایف در طول حالت compaction
- **پیشنهاد پرامپت** (Prompt Suggestions): پیشنهاد هوشمند دستور یا پرامپت بر اساس context
- **درخت‌های Git** (Git Worktrees): شاخه‌های مختص که برای کار موازی مناسب‌اند
- **تعمیق‌نمایی** (Sandboxing): تعیین‌نماینده‌ی فایل‌سیستم و شبکه‌ی سطح‌ضرر
- **تنظیمات مدیریت شده** (Managed Settings): برای نصب سازمانی از طریق plist، Registry یا فایل‌های مدیریت‌شده
- **پیکربندی** (Configuration): پیکربندی رفتار با فایل‌های JSON

## حالت برنامه‌ریزی

گام‌بندی نمونه‌ها در [planning-mode-examples.md](planning-mode-examples.md) را مشاهده کنید.

حالت برنامه‌ریزی، قبل از پیاده‌سازی در عمل، به کلود اجازه می‌دهد وظایف پیچیده را تجزیه و تحلیل کند و یک طرح دقیق که می‌توانید بازبینی و تأیید کنید تولید کنید.

### چه چیست؟

حالت برنامه‌ریزی، یک فرآیند دوگانه است:

1. **مرحله برنامه‌ریزی**: کلود وظیفه را تحلیل می‌کند و یک طرح دقیق تولید می‌کند
2. **مرحله پیاده‌سازی**: پس از تأیید شما، کلود طرح را اجرا می‌کند

### چه زمانی استفاده شود؟

✅ مناسب برای:

- بازسازی چندفایل پیچیده
- توسعه قابلیت جدید
- تغییر معماری
- Migration پایگاه‌داده
- طراحی API بزرگ

❌ تنبیه‌شده برای:

- رفع باگ ساده
- تغییرات فرمت
- ویرایش یک‌فایل
- پرس‌وجوهای سریع

### چگونه شروع شود؟

**دستور Slash:**

```bash
/plan Implement user authentication system
```

**پارامتر CLI:**

```bash
claude --permission-mode plan
```

**تنظیم به‌عنوان پیش‌فرض:**

```json
{
  "permissions": {
    "defaultMode": "plan"
  }
}
```

**میانبرهای کلید:**

- `Shift + Tab` - تغییر حالت مجوز (شامل plan)
- `Alt + M` - تغییر حالت مجوز (فقط برای ویندوز و زمانی که VT input mode فعال نیست)

### مزایای حالت برنامه‌ریزی

- طرز پیاده‌سازی ساخت‌یافته‌تر: مراحل را به چشم می‌خورد
- بازبینی و تأیید: ابتدا طرح، سپس اجرا
- شناسایی خطر: مسائل بالقوه را از قبل با شمرد
- چک‌پoints واضح: مراحل و مراحل مشخص مشخص

## تفکر گسترده (Extended Thinking)

برای مسائل پیچیده، استدلال عمیق‌تر برای آن‌ها جاهایی است.

```bash
# استدلال را با سطح effort کنترل کنید
/effort high
```

### چه زمانی استفاده شود؟

- تحلیل کد پیچیده
- معماری‌ها و تصمیم‌گیری‌ها
- حل مسائل طراحی
- استuario‌ساز و طراح چالش‌برانگیز

## حالت خودکار (Auto Mode)

اجرای خودکار با بررسی امنیت پس‌زمینه در هر مرحله.

### فعال‌سازی

```bash
# حالت خودکار را فعال کنید
claude --enable-auto-mode

# یا از طریق تنظیمات
{
  "autoMode": {
    "enabled": true
  }
}
```

### نکاتCharsets

- توسط تحلیل‌گر امنیت پس‌زمینه کنترل می‌شود
- پیش‌فرض: `Shift+Tab` برای تغییر
- گزینه‌های خودکار را با `--permission-mode auto` فعال کنید

## وظایف پس‌زمینه

اجرای وظایف طولانی‌مدت بدون مسدود کردن سیشن فعلی.

```bash
/tasks               # مشاهده و مدیریت وظایف پس‌زمینه (مثیل: /bashes)
```

### بهترین شیوه‌ها

- برای وظایف طولانی، هم‌زمانی و قابل پاراللیز کردن
- اطمینان از تنظیم زمان‌بندی و شفافیت
- یادداشت‌گذاری قابلیت‌های سریع

## وظایف زمان‌بندی شده

بطور دوره‌ای اجرا کردن وظایف به صورت `/loop`:

```bash
/loop every 30m "Run tests and report failures"
/loop every 2h "Check for dependency updates"
/loop every 1d "Generate daily summary of code changes"
```

## حالت‌های مجاز (Permission Modes)

| حالت | توضیح | سناریو کاربرد |
|-------|------|----------|
| `default` | حالت مجاز استاندارد | توسعه عمومی |
| `acceptEdits` | پذیرش خودکار ویرایش‌های فایل | گردش کار اطمینان‌ورزی |
| `plan` | فقط تحلیل، بدون ویرایش فایل | بازبینی، برنامه‌ریزی |
| `auto` | تایید خودکار عملیات امن | تعادل خود stoppage و امنیت |
| `dontAsk` | فقط اجرای ابزارهای تایید شده قبلی، بقیه به‌طور خودکار رد شده | کاربر حرفه‌ای / خودکار |
| `bypassPermissions` | کاملاً مجاز | CI/CD، اسکریپت‌های اطمینان |

### انتخاب حالت مجاز

- از حالت‌های کم‌امن به‌عنوان پیش‌فرض شروع کنید
- تنها مؤقت‌انه رها کنید که لازمه باشد
- برای پیچیدگی بالا یا خودکار‌سازی از `dontAsk` یا `bypassPermissions` استفاده کنید

## حالت headless (چاپ)

اجرای بدون تعامل با استفاده از ریپورت، برای خودکار‌سازی و CI/CD.

```bash
claude -p "Run all tests"
cat error.log | claude -p "explain this error"
claude -p --output-format json "list all functions in src/"
```

## مدیریت سیشن

```bash
/resume                # بازیابی سیشن قبلی
/rename "Feature"      # نام‌گذاری سیشن فعلی
/fork                  # کپی سیشن فعلی به سیشن پس‌زمینه قابل جدا
claude -c              # ادامه به سیشن اخیر
claude -r "Feature"    # بازیابی سیشن با نام/شناسه
```

## پیکربندی و تنظیمات

### مکان‌های فایل پیکربندی

- `~/.claude/settings.json`
- `.claude/settings.json`
- `.claude/settings.local.json`

### مثال پیکربندی کامل

```json
{
  "permissions": {
    "defaultMode": "plan"
  },
  "thinking": {
    "enabled": true,
    "effort": "high"
  },
  "autoCheckpoint": true
}
```

### متغیرهای محیطی

| متغیر | توضیح |
|---------|-------|
| `ANTHROPIC_API_KEY` | کلید API |
| `CLAUDE_MODEL` | مدل پیش‌فرض |
| `CLAUDE_EFFORT` | تلاش پیش‌فرض استدلال |
| `CLAUDE_WORKING_DIRECTORY` | دایرکتوری کاری پیش‌فرض |
| `CLAUDE_OUTPUT_FORMAT` | فرمت خروجی پیش‌فرض |
| `CLAUDE_MCP_CONFIG` | پیکربندی MCP پیش‌فرض |
