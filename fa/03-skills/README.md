# راهنمای مهارت‌های Agent (Skills)

## مرور کلی

مهارت‌ها بسته‌های قابلیت‌های قابل استفاده مجدد و خود-حادثه-trigger هستند. یک مهارت معمولاً شامل فایل `SKILL.md`، فایل‌های مرجع، اسکریپت‌ها و قالب‌ها است. Claude در سناریوهای مناسبی آن را به صورت خودکار بارگذاری می‌کند.

### مزایای اصلی

- قابل استفاده مجدد
- بارگذاری یکدست
- می‌توان اسکریپت‌ها، قالب‌ها و توضیحات را در یکجا قرار داد
- برای استانداردسازی فرایندها مناسب است

## نحوه عملکرد مهارت‌ها: افشای یکدست

مهارت‌ها محتوای را در یک‌باره به زمینه نمی‌زینند، بلکه بر اساس نیاز بارگذاری می‌شوند.

### سه لایه بارگذاری

1. **فقط توضیحات**: ابتدا判断 کنید که آیا این مهارت مرتبط است یا خیر
2. **بارگذاری `SKILL.md`**: خواندن دستورالعمل‌های اصلی
3. **بارگذاری پرونده‌های پشتیبانی بر اساس نیاز**: اسکریپت‌ها، قالب‌ها، منابع مرجع

## جریان بارگذاری مهارت

1. Claude دایرکتوریه مهارت‌ها را اسکن می‌کند
2. بر اساس توضیحات،判断 می‌کند آیا با وظیفه فعلی مطابقت دارد یا خیر
3. فایل `SKILL.md` را می‌خواند
4. در صورت نیاز، پرونده‌های اسکریپت و کمکی را بارگذاری می‌کند

## نوع و موقعیت مهارت

مهارت‌ها می‌توانند در :
- دایرکتوری پروژه زیر `.claude/skills/` قرار گیرند
- دایرکتوری کاربر زیر `~/.claude/skills/` قرار گیرند

### کشف خودکار

از حالتی که ساختار دایرکتوری صحیح باشد، Claude به صورت خودکار این مهارت‌ها را کشف می‌کند.

## ایجاد مهارت‌های سفارشی

### ساختار دایرکتوری پایه

```text
my-skill/
└── SKILL.md
```

### قالب `SKILL.md`

```yaml
---
name: my-skill
description: کاربرد این مهارت و چه زمانی فعال شود
---

# نام مهارت شما

## دستورالعمل‌ها

## مثال‌ها
```

### فیلدهای پیشنهادی

- `description` (پیشنهادی): توضیح دهید این مهارت چه می‌کند و چه زمانی استفاده شود؛ Claude برای تشخیص فعال بودن مهارت به این مراجعه می‌کند
- `name` (اختیاری): در صورت حذف، نام پیش‌فرض نام دایرکتوری مهارت است

### فیلدهای اختیاری frontmatter

- `argument-hint`
- `allowed-tools`
- `model`
- `disable-model-invocation`
- `user-invocable`
- `context`
- `agent`
- `hooks`

## نوع محتوای مهارت

### محتوای مرجع

مناسب برای قوانین، استانداردها، قطعه‌های مستندات و مثال‌ها.

### محتوای وظیفه

مناسب برای مراحل مشخص، جریان کار اجرا و فرمت‌های خروجی مورد نیاز.

## کنترل فراخوانی مهارت

می‌توانید از طریق `disable-model-invocation`، `user-invocable` و لیست سفید ابزارها کنترل کنید که آیا Claude می‌تواند به صورت خودکار این مهارت را فراخوانی کند یا خیر.

## جایگزینی رشته

مهارت‌ها از جایگزینی `$ARGUMENTS`، `$0`، `$1` و غیره پشتیبانی می‌کنند.

### تزیر بSLAM! د---

### تزیر بSLAM! د---

در می‌توانید در پرompt خود، نتایج اجرای دستورات شل را وارد کنید:

> **نکته (v2.1.299)**:胡ک‌های `UserPromptSubmit` قبل از گسترش دستورات اجرا می‌شوند، بنابراین مانع شدن از هر胡کی که این پرompt را مانع می‌شود، باعث متوقف شدن این دستورات `!` نیز می‌شود.

```md
- وضعیت فعلی git: !`git status`
- diff فعلی: !`git diff HEAD`
- شاخه فعلی: !`git branch --show-current`
```

## اجرای مهارت‌ها در subagent

برخی مهارت‌ها برای اجرا در زمینه ایزوله مناسب هستند، تا تأثیر بر جلسه اصلی کاهش یابد.

## مثال‌های کاربردی

### مثال ۱: مهارت بازبینی کد

یک مهارت بازبینی معمولی شامل موارد زیر است:

- الگو بازبینی
- سطح خطا
- فرمت خروجی
- ابعاد 필요가 توجه شود

### مثال ۲: مهارت تصویرسازی پایگاه کد

می‌توانید ساختار پایگاه کد، وابستگی‌ها و مرز ماژول‌ها را برای Claude خلاصه کنید تا درک سریع‌تری داشته باشد.

### مثال ۳: مهارت استقرار (فقط فعال شدن کاربر)

مناسب برای عملیات با اثر جانبی، مثلاً استقرار در محیط تولید. معمولاً به همراه `disable-model-invocation: true` استفاده می‌شود.

### مثال ۴: مهارت لحن برند

برای بررسی اینکه آیا خروجی با لحن، نغمه و سبک برند مطابقت دارد یا خیر استفاده می‌شود.

### مثال ۵: مهارت تولید `CLAUDE.md`

می‌تواند از مستندات پروژه `CLAUDE.md` را تولید یا تکمیل کند.

### مثال ۶: مهارت بازسازی با اسکریپت

ترکیب رایج شامل:

- `SKILL.md`
- `scripts/`
- `templates/`
- `references/`

## مدیریت مهارت‌ها

### مشاهده مهارت‌های موجود

```bash
/skills
```

### تست یک مهارت

آن را در دایرکتوری تست یا پروژه موقت قرار دهید و سپس از طریق دستور مربوطه فعال کنید.

### به‌روزرسانی یک مهارت

بعد از ویرایش `SKILL.md` یا پرونده‌های پشتیبانی، جلسه را دوباره باز کنید یا بارگذاری مجدد کنید.

### محدود کردن دسترسی Claude به مهارت‌ها

می‌توانید از طریق پیکربندی دسترسی، اجازه دسترسی Claude فقط به برخی مهارت‌ها را بدهید.

## بهترین شیوه‌ها

### ۱. توضیح باید خاص باشد

فیلد `description` را به گونه‌ای بنویسید که به وضوح توضیح دهد این مهارت چه زمانی فعال می‌شود.

### ۲. تمرکز را حفظ کنید

یک مهارت یک مشکل را حل می‌کند، همه چیز را در آن قرار ندهید.

### ۳. کلمات فعال‌سازی را شامل کنید

در توضیح، کلمات کلیدی مربوطه را اضافه کنید تا Claude دقیق‌تر آن را انتخاب کند.

### ۴. `SKILL.md` خیلی طولانی نباشد

سعی کنید تا ۵۰۰ خط محدود شود، اگر بیشتر است فایل‌های پشتیبانی را تفکیک کنید.

### ۵. به پرونده‌های پشتیبانی ارجاع دهید

محتوای تکرارپذیر را به اسکریپت‌ها یا فایل‌های مرجع منتقل کنید، فایل اصلی فقط دستورالعمل‌های اصلی را نگه دارد.

## عیب‌یابی

### مرجع سریع

- بررسی کنید ساختار دایرکتوری صحیح است
- بررسی کنید frontmatter `SKILL.md` معتبر است
- بررسی کنید نام مهارت با نام فراخوانی مطابقت دارد

### مهارت فعال نمی‌شود

- بررسی کنید توضیح کافی خاص است
- بررسی کنید دایرکتوری در دامنه دید Claude است
- بررسی کنید که به یک مهارت با ارجحیت بالاتر پوشش داده نشده است

### مهارت خیلی زیاد فعال می‌شود

- توضیحات را تشدید کنید
- شرایط محدود دیگری اضافه کنید
- از کلمات فعال‌سازی خاص‌تر استفاده کنید

### Claude همه مهارت‌ها را نمی‌بیند

- مسیر را بررسی کنید
- مجوزها را بررسی کنید
- جلسه را دوباره بارگذاری کنید

## نکات امنیتی

- کلیدها را در مهارت هاردکد نکنید
- برای عملیات با اثر جانبی، فعال شدن کاربر را حفظ کنید
- برای مهارت‌های خود-حادثه-trigger، مرزهای واضح تعریف کنید

## مهارت‌ها در برابر سایر ویژگی‌ها

| ویژگی | روش فعال‌سازی | سنarlaigh مناسب |
|------|----------|----------|
| مهارت‌ها | خودکار/نیمه-خودکار | قابلیت‌های قابل استفاده مجدد، استانداردسازی فرایندها |
| دستورات Slash | دستی | دستورات سریع |
| Subagents | وفاداری خودکار | وظایف ایزوله |
|胡ک‌ها | Event-trigger | اتوماسیون و اعتبارسنجی |

## مهارت‌های داخلی

Claude Code همراه با برخی مهارت‌های داخلی است، مثلاً برای دسته‌پردازی، اشکال‌زدایی، ساده‌سازی و محتواهای مرتبط با Claude API.

## به اشتراک گذاشتن مهارت‌ها

### مهارت‌های پروژه (اشتراک‌گذاری تیمی)

مهارت را در دایرکتوری پروژه قرار دهید، أعضاء تیم می‌توانند از آن استفاده کنند.

### مهارت‌های شخصی

```bash
# کپی به دایرکتوری شخصی
mkdir -p ~/.claude/skills

# اسکریپت‌ها را قابل اجرا کنید
chmod +x ~/.claude/skills/*/scripts/*
```

### توزیع پلاگین

می‌توانید مهارت‌ها را به عنوان بخشی از یک پلاگین منتشر کنید.

## ادامه یادگیری

اگر می‌خواهید مجموعه کامل مهارت‌ها را مدیریت کنید، می‌توانید یکجموعة مهارت یا مدیر مهارت بسازید، برای کشف، به‌روزرسانی و توزیع یکپارچه.
